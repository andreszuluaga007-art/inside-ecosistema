# INSIDE

Haz de tu mente tu hogar.

Sitio estático en español con prácticas educativas de reflexión, observación y toma de perspectiva. La carpeta pública es `dist`.

## Publicación en Cloudflare Pages

- Rama: `main`.
- Configuración: sin framework.
- Comando de compilación: ninguno.
- Carpeta de salida: `dist`.

Las fotografías y los sonidos se sirven desde el propio sitio; sus créditos están incluidos en los archivos de la web. Las reflexiones personales no se envían ni se guardan. El contacto abre un borrador en el correo de la persona.

El contenido es educativo y no constituye una evaluación psicológica ni sustituye el acompañamiento profesional.
